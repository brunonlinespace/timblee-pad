# Timblee Pad 0.2.3

0.2.3 is a narrowly scoped publication/packaging correction based on 0.2.2. It restores the approved public README filename at source root to `README.md`.

## Changes

- Renames the locked public root file from `README` to `README.md`.
- Updates the portable-root QA contract to require `README.md` alongside `main.py`, `suite-pythoine-component.json`, and `timblee_pad/`.
- Updates the Fedora AppImage builder to require `${PROJECT_ROOT}/README.md` and retain its SHA-256 in build provenance.
- Preserves the 0.2.2 Sheepy editor-scrolling/gutter corrective unchanged.
- Synchronizes release/package identity to `0.2.3`.

No editor, Library, Preview, shortcut, theme, file-handling, dependency, branding, document-type, or AppImage-policy behavior changes are included.
